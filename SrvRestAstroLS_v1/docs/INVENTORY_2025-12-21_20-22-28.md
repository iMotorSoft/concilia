## Endpoints (API)

- **SSE stream**
  - `routes/v1/agui_notify.py:39-63` (notify_stream)
  - Metodo: `GET /api/ag-ui/notify/stream?threadId=...`
  - Input: query `threadId` (topic SSE)
  - Output: stream SSE con eventos `{type, payload}`
  - Auth/tenant: none; aislamiento actual por `threadId` (en memoria)
  - Dependencias: `_SUBS`, `_PENDING` (memoria local)

- **Chat turn (orquestador UI)**
  - `routes/v1/chat_concilia.py:19-49` (chat_turn)
  - Metodo: `POST /api/chat/turn`
  - Input JSON: `{ text, threadId }`
  - Output: `{ ok: true }` y emite SSE `TEXT_MESSAGE_REQUEST_UPLOAD`
  - Auth/tenant: none; controla flow por `threadId`

- **Upload legacy (bank-movements)**
  - `routes/v1/uploads_concilia.py:18-116` (upload_bank_movements)
  - Metodo: `POST /api/uploads/bank-movements`
  - Input multipart: `file`, `threadId`, `correlationId`, `account_id`, `period`, `profile_id`
  - Output JSON: `{ ok, source_file_id, original_uri, kind, bytes_written, filename }`
  - SSE: `INGEST_PREVIEW`
  - Auth/tenant: none
  - Dependencias: `services/ingest/sniff_bank.py` (sniff_file), `globalVar.resolve_storage_uri`

- **Upload ingest (v1)**
  - `routes/v1/uploads_ingest.py:37-143` (uploads_ingest)
  - Metodo: `POST /api/uploads/ingest`
  - Input multipart: `file`, `threadId`, `role` (query o form: extracto|contable)
  - Output JSON: `{ ok, role, source_file_id, original_uri, kind, bytes_written, filename }`
  - SSE: `INGEST_PREVIEW`
  - Auth/tenant: none

- **Upload ingest (v2 + alias)**
  - `routes/v1/uploads_v2_concilia.py:834-843` (upload_ingest_v2, upload_ingest_alias)
  - Handler: `routes/v1/uploads_v2_concilia.py:580-830` (_handle_upload)
  - Metodo: `POST /api/uploads/v2/ingest`
  - Input multipart: `file` (1..N), `threadId`, `role` (query, extracto|contable)
  - Output JSON: `{ ok, original_uri, role, uploads_count, bytes_written, filename }`
  - SSE: `INGEST_PREVIEW` (incluye `meta.uploads` y `coverage`)
  - Auth/tenant: none

- **Ingest confirm**
  - `routes/v1/ingest_confirm.py:117-185` (ingest_confirm)
  - Metodo: `POST /api/ingest/confirm`
  - Input multipart: `threadId`, `role`, `source_file_id`, `original_uri`, `bank`, `period_from`, `period_to`
  - Output JSON: `{ ok, message }`
  - SSE: `INGEST_CANONICAL_READY`, `READY_TO_RECONCILE`, `TOAST`
  - Auth/tenant: none

- **Reconcile start (full)**
  - `routes/v1/reconcile_start.py:478-698` (reconcile_start)
  - Metodo: `POST /api/reconcile/start`
  - Input form: `threadId`, `uri_extracto`, `uri_contable`, `days_window`
  - Output JSON: `{ ok, summary }`
  - SSE: `RUN_START`, `RECONCILE_STAGE`, `RESULTS_READY`, `TOAST`
  - Auth/tenant: none; telemetry DB usa legacy `concilia_*` (via services/db_concilia_legacy.py)

- **Reconcile quick**
  - `routes/v1/reconcile_quick.py:38-88` (reconcile_quick)
  - Metodo: `POST /api/reconcile/quick`
  - Input multipart: `bank_file`, `gl_file`, `days_tolerance`, `threadId`
  - Output JSON: `{ ok, bank_uri, gl_uri, result{summary, matched, unmatched_*} }`
  - SSE: `RECONCILE_SNAPSHOT`

- **Summary**
  - `routes/v1/reconcile_summary.py:170-203` (reconcile_summary)
  - `routes/v1/reconcile_summary.py:205-224` (reconcile_summary_head)
  - `routes/v1/reconcile_summary.py:227-246` (reconcile_summary_descomposicion)
  - Metodo: `POST /api/reconcile/summary`, `/summary/head`, `/summary/descomposicion`
  - Input form: `uri_extracto`, `uri_contable`, `days_window`
  - Output JSON: `summary` o `descomposicion`
  - Dependencias: `_compute_pipeline` de `routes/v1/reconcile_details.py:325-385`

- **Details**
  - `routes/v1/reconcile_details.py:481-520` (reconcile_details)
  - `routes/v1/reconcile_details.py:525-563` (reconcile_details_no_banco)
  - `routes/v1/reconcile_details.py:569-613` (reconcile_details_pares)
  - `routes/v1/reconcile_details.py:619-658` (reconcile_details_no_contable)
  - `routes/v1/reconcile_details.py:664-715` (reconcile_details_n1_grupos)
  - `routes/v1/reconcile_details.py:720-770` (reconcile_details_n1_sugeridos)
  - Metodo: `POST /api/reconcile/details*`
  - Input form: `uri_extracto`, `uri_contable`, `days_window`
  - Output JSON: rows + totals (con limites)
