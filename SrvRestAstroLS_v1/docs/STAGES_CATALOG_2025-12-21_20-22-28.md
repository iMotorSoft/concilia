## Payload recomendado (STAGE)

Minimo recomendado:

```json
{
  "type": "RECONCILE_STAGE",
  "payload": {
    "run_id": "<uuid>",
    "stage": "LOAD_EXTRACTO",
    "status": "start|progress|done|error",
    "message": "Cargando extracto...",
    "progress": { "current": 0, "total": 0, "pct": 0 },
    "timing_ms": 1200,
    "metrics": { "rows": 12000 }
  }
}
```

Ejemplo real actual (sin progress):
- `routes/v1/reconcile_start.py:512-521` (RECONCILE_STAGE payload)

## Recomendaciones

- Mantener `stage` y `status` consistentes con UI (ReconciliarApp usa `RUN_START`/`RESULTS_READY` hoy; `RECONCILE_STAGE` ya existe).
- El `progress` puede ser nulo mientras no haya granularidad (mantener `start/done`).
